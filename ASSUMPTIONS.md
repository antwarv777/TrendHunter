# ASSUMPTIONS (допущения MVP)

1. **Навигация без роутера.** Внутренний state в App.tsx вместо react-router — проще, роутер добавим при появлении URL-нужн.
2. **Покупка из карточки** = confirm() + мгновенная мок-оплата конкретного тренда. Экран «Доступ» — для выбора тарифа.
3. **Генератор** — детерминированный: одна ниша → один и тот же результат (сдвиг по длине строки). Это фича, а не баг, для MVP.
4. **Доступ ко всему** — константная цена 499 ₽, зашита в PaywallScreen.
5. **Контент** — в src/data/trends.json, типизирован через `as Trend[]` в src/data/trends.ts. Разовый конвертер: scripts/to-json.cjs.
6. **localStorage-ключи**: `th_purchases_v1`, `th_all_access_v1`. Смена схемы = инкремент версии.
7. **Telegram** подключён скриптом telegram-web-app.js, @telegram-apps/sdk не нужен на этом этапе.
