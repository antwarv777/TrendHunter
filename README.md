# Охотник за трендами (MVP)

Мобильное веб-приложение (Telegram Mini App ready): лента трендов с идеями цифровых микропродуктов за 99–299 ₽.

## Запуск

```bash
cd D:\Завод\trend-hunter
npm install
npm run dev        # разработка
npm run build      # прод-сборка
```

Браузерная версия: http://localhost:5173. В Telegram Mini App подключается автоматически через `telegram-web-app.js`; вне Telegram работает как обычный сайт.

## Как пользоваться на телефоне (без VPS)

Приложение — статика, ему не нужен сервер 24/7. Есть 3 способа, от простого к «настоящему APK»:

### 1. PWA прямо сейчас (0 настроек)
Запусти `npm run dev`, открой адрес с телефона (в конфиге включён `host: true`).
В Chrome (Android): меню → «Установить приложение». Появится иконка на рабочем столе, открывается в полноэкранном режиме без адресной строки.

### 2. GitHub Pages (бесплатно, 24/7, обновляется по пушу)
```bash
cd D:\Завод\trend-hunter
git init
git add .
git commit -m "MVP: trend-hunter"
# создай пустой репозиторий trend-hunter на github.com, затем:
git remote add origin https://github.com/<ТВОЙ_НИК>/trend-hunter.git
git branch -M main
git push -u origin main
```
В настройках репо: Settings → Pages → Source: **GitHub Actions**.
Через ~2 мин сайт будет на `https://<ник>.github.io/trend-hunter/`. Деплой автоматический при каждом пуше (workflow `.github/workflows/deploy.yml`).

### 3. Настоящий APK через PWABuilder (бесплатно, без Android Studio)
После деплоя на GitHub Pages:
1. Открой [pwabuilder.com](https://www.pwabuilder.com), вставь URL своего сайта.
2. Нажми Package for stores → **Android**.
3. Скачай APK: `app-release-signed.apk` ставится на телефон (разреши «установку из неизвестных источников»). Тот же файл можно потом выложить в Telegram-канал для пользователей.

APK — это тот же сайт в нативной обёртке. Обновления контента — через git push (в PWA-версии подхватятся сразу, APK-версию нужно пересобирать).

## Telegram-бот доставки

`telegram/bot.py` — выдача файлов гайдов по команде `/get <id>` (см. докстринг в файле). Для работы 24/7 не нужен: гайды зашиты в сам сайт, а реальная доставка понадобится только вместе с реальной оплатой (ROADMAP v0.2). Если позже понадобится постоянный бот — бесплатного тарифа PythonAnywhere достаточно, VPS не требуется.

## Стек
Vite + React 18 + TypeScript, обычный CSS. Без бэкенда, БД, авторизации и реальных платежей.

## Что есть в MVP
- Лента из 10 трендов с фильтрами (цена, время, сложность) и поиском
- Детальный экран тренда с инструкцией (платной или бесплатной)
- Мок-оплата: разовый гайд или доступ ко всему, состояние в localStorage
- Локальный генератор идей по нише (без AI API)
- Контент в src/data/trends.json — правится без изменения кода

Документация развития — в ROADMAP.md, допущения — в ASSUMPTIONS.md.
